MỘT CHÚT HƯỚNG DẪN

Bạn chỉ cần một ý tưởng.

Nhập chủ đề, chọn sắc thái rồi bấm tạo. Bạn có thể để giọng đọc, nhạc và phụ đề ở mặc định.

  1. Kịch bản: Claude Code hoặc Codex trên máy viết nội dung bằng phiên đăng nhập sẵn có.
  2. Hình ảnh: Mặc định, Codex trên máy tự vẽ ảnh riêng cho từng cảnh bằng gói ChatGPT của bạn, không cần API key. Hoặc chọn Gemini: studio chia cảnh theo mốc giây của giọng đọc và viết prompt riêng cho từng cảnh. Bạn dán prompt vào Gemini trên trình duyệt, tải ảnh về, studio tự xếp ảnh và dựng. Không dùng API trả phí. Chọn “Ảnh thư viện” nếu muốn chạy tự động bằng ảnh Unsplash có sẵn.
  3. Âm thanh: Giọng đọc tiếng Việt qua dịch vụ Edge TTS trực tuyến; nhạc ambient được tổng hợp ngay trên máy.
  4. Video: Dựng tại máy thành MP4 dọc 720 × 1280, có phụ đề theo lời đọc. Thời lượng thực tế phụ thuộc kịch bản.

Giữ máy hoạt động trong khi tạo. Nếu mất mạng hoặc hết quota, bạn có thể thử lại từ bước đã lưu. Web không tự đăng lên TikTok.

Video nằm trong thư mục .studio/jobs/ của dự án. Lần sau mở file Mo Lang Studio.command để bật web.
